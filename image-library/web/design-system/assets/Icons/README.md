# Icons

本系統的 28 個介面圖示：24×24 格線、圓角端點與轉角、筆畫 1.7（regular），單色黑墨 `#000000`。用 `<img>` 顯示時無法繼承文字顏色——在介面中請改用元件 `Icon`（`currentColor`、可選字重 regular／medium／semibold／bold），讓它跟著 `label-primary`、`accent` 等 token 變色。

這些是 SF Symbols 的**網頁替身**，供原型與預覽使用；原生 Apple 平台 App 一律換成對應的 SF Symbol：

| 檔名 | 用途 | 對應 SF Symbol |
|---|---|---|
| chevron-left／right／down | 返回、展開指示、下拉 | chevron.left／right／down |
| chevron-up-down | 彈出式按鈕 | chevron.up.chevron.down |
| checkmark、xmark | 完成／勾選、關閉／取消 | checkmark、xmark |
| plus、minus | 加入、移除、Stepper | plus、minus |
| magnifyingglass | 搜尋 | magnifyingglass |
| ellipsis | 更多 | ellipsis |
| sidebar | 顯示／隱藏側邊欄 | sidebar.left |
| share | 分享 | square.and.arrow.up |
| trash | 刪除 | trash |
| slider-horizontal | 設定、調整 | slider.horizontal.3 |
| house、folder、photo、music-note、person、bell、clock | 分頁與分類 | house、folder、photo、music.note、person、bell、clock |
| info、exclamation-triangle | 資訊、警告（少用） | info.circle、exclamationmark.triangle |
| star | 個人收藏 | star |
| compose | 撰寫、編輯 | square.and.pencil |
| external-drive | 外接硬碟 | externaldrive |
| undo | 還原 | arrow.uturn.backward |
| filter | 篩選、列表檢視 | line.3.horizontal.decrease |
