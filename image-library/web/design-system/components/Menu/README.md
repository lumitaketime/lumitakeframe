選單面板：在需要時才顯示指令、選項或狀態，節省空間。

**使用者提供**：`items` 陣列——`{label, icon, shortcut, checked, disabled, destructive, submenu, onSelect}`，或 `{separator: true}`、`{header: '…'}`；`onSelect`、`onClose`、`width`、`autoFocus`。

## 規則（HIG Menus）
- 每個項目清楚簡短；動作用動詞或動詞片語（檢視、關閉、選取）。英文用標題式大小寫，並省略冠詞。
- 不可用的項目變暗且不回應；即使全部不可用，選單本身仍保持可開啟。
- 需要更多資訊才能完成的動作加刪節號「…」。
- 圖示少用：同一組裡要嘛全部有圖示、要嘛全部沒有；找不到清楚圖示就不要放。
- 重要或常用項目排前面；相關項目用分隔線分組。
- 子選單少用、只有一層；同一組中有超過兩個項目重複同一詞時可考慮子選單；子選單項目約五個以上就考慮另開選單。
- 切換類項目：用可變標籤（顯示地圖／隱藏地圖），或以勾號表示目前生效的屬性。
- iOS／iPadOS 的選單有 small（頂端四個純符號）、medium（三個符號＋短標籤）、large（預設，全部列表）三種版面。

## 平台
- macOS：列高約 24pt、13pt 字；滑過或鍵盤聚焦時以強調色反白（`accent` + `on-accent`）。
- iOS：列高 44pt、17pt 字；標籤在前、圖示在尾端。
- 破壞性項目為系統紅（`destructive`）；在玻璃上的紅字對比約 3.5:1，屬 Apple 原始配對，增強對比主題 ≥ 4.5:1。
