介面圖示：本系統自繪的 28 個 24×24 線條圖示，供網頁預覽與原型使用。

**使用者提供**：`name`、`size`（預設 17，對齊內文）、`weight`（`regular`／`medium`／`semibold`／`bold`，配合旁邊文字的字重）、`title`（有意義時的替代文字；沒有就視為裝飾）。

- 原生 Apple 平台 App 一律改用 **SF Symbols**；本組圖示只是網頁替身，名稱對應常見符號（`share` ≈ square.and.arrow.up、`compose` ≈ square.and.pencil、`magnifyingglass` 等）。
- HIG Icons：所有介面圖示保持一致的尺寸、細節程度、筆畫粗細與透視；筆畫粗細與相鄰文字的字重相配。
- 只在必要時提供「選取狀態」版本；工具列、Tab bar、按鈕的選取狀態由系統處理。
- 為有意義的自訂圖示提供替代文字（`title`）。
- 常用動作使用通用符號：剪下、拷貝、完成（checkmark）、取消／關閉（xmark）、刪除（trash）、分享、加入（plus）、更多（ellipsis）、搜尋、篩選。
- 不要畫 Apple 硬體產品的仿製圖；SF Symbols 依授權不可用在 App 圖示或商標用途。
