Tab bar 讓人在 App 的頂層區塊之間切換，並保留各區塊的導覽狀態；iOS 中它浮在內容上的 Liquid Glass 上。

**使用者提供**：`items`（`{value, label, icon, badge}`）、`value`／`defaultValue`、`onChange`、`search`（`{label}`，在尾端顯示獨立的搜尋分頁）、`accessory`（例如迷你播放器）、`layout`（`compact`：圖示在標籤上方；`regular`：iPad，圖示在標籤旁）。

## 規則（HIG Tab bars）
- 用來**導覽**，不是用來執行動作——對目前畫面的動作放工具列。
- 在各區塊間移動時保持可見（被模態視圖蓋住時例外）。
- 分頁只放需要的數量；避免溢出成「更多」分頁。iPadOS 若允許自訂，預設五個以內。
- 內容暫時不可用時不要停用或隱藏分頁，而是說明為什麼是空的。
- 每個分頁都有標籤，最好一個詞；圖示偏好實心版本。
- 徽章只標示重要資訊：紅色橢圓配白色數字或驚嘆號（`badge`／`on-badge`）。
- 標籤顏色不要跟內容層背景相近；偏好單色，或對比明確的強調色。
- iOS：浮在底部；搜尋分頁在尾端；附屬列可在捲動時縮進 Tab bar。iPadOS：在畫面頂端，可轉換成側邊欄。macOS 用側邊欄或工具列，watchOS 不支援。

標籤字級取 11pt（HIG iOS 最小字級）。選取分頁的強調色文字在玻璃上的對比依底下內容而定；必要資訊不要只放在標籤顏色上。
