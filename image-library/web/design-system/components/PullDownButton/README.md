下拉按鈕：按下後展開一份**動作**選單；要讓人選一個值時改用 PopUpButton。

**使用者提供**：`label`（純圖示時當作無障礙名稱）、`icon`、`items`（`Menu` 的項目格式）、`variant`、`iconOnly`、`align`（`start`／`end`，選單對齊）。

- 適用：一組相關動作、可多選的項目，或需要子選單時（HIG Pop-up buttons 指出這些情況用 pull-down）。
- 選單項目以動詞開頭、標題式大小寫（英文）、需要更多資訊時加「…」。
- 最重要、最常用的項目排前面；用分隔線分組。
- 以 Escape 或點選外部關閉；方向鍵在項目間移動。
