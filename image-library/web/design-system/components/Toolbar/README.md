工具列沿著視窗或畫面的頂端（或底端）提供標題、導覽與最常用的動作，分為前端、中央、尾端三區。

**使用者提供**：`title`、`subtitle`（macOS）、`leading`／`center`／`trailing`——每一區是「群組陣列」，每個群組是一組 `{icon, label, onClick, prominent, text, disabled, node}`，同一群組共用一塊玻璃；`largeTitle`（iOS）、`edgeEffect`（捲動邊緣效果，預設開）。

## 規則（HIG Toolbars）
- 慎選項目，並定義視窗變窄時哪些項目先收進溢出選單；macOS、iPadOS 系統會自動加溢出選單，不要自己加。
- 前端：返回、顯示／隱藏側邊欄，然後是標題與文件選單（不可自訂）。中央：常用控制項（macOS／iPadOS 可自訂）。尾端：必留項目、檢查器、搜尋、「更多」選單與主要動作（永遠可見）。
- **群組最多三組**；依功能與頻率分組；文字動作與符號動作分開並加固定間距。
- 只有**一個**主要動作（`prominent`，如「完成」「送出」），放在尾端。
- 減少自訂背景與上色控制項；顏色留給內容層，需要時用捲動邊緣效果——本元件以 `edgeEffect` 實作。
- 用標準的返回與關閉符號，不用「返回」「關閉」文字。偏好沒有外框的簡單符號。
- 每個視窗給有用的標題，不要用 App 名稱當標題，**少於 15 個字元**。
- macOS：每個工具列項目也必須存在於選單列的指令中。
- iOS：只放最重要的項目；用大標題（`largeTitle`）幫助定位。
