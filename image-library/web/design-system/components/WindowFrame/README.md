macOS 視窗框，**只**用於版面示意與網頁原型；原生 App 一律使用系統視窗。

**使用者提供**：`title`、`width`、`height`、`sidebar`（通常是 `Sidebar`）、`toolbar`（通常是 `Toolbar`）、`inactive`、子元素（內容區）。

- HIG Windows：不要自製視窗框或視窗控制，也不要模仿系統外觀——這個元件只為了在設計稿中呈現版面。
- 側邊欄浮在內容之上，內容延伸到側邊欄與工具列下方。
- 不要把重要資訊或動作放在視窗底部的底列（人們常把視窗底緣移出螢幕）；底列只放少量相關資訊（如 Finder 狀態列）。
- 自訂視窗要有主視窗、關鍵視窗、非作用中三種外觀（`inactive` 會把視窗按鈕變灰）。
- 使用者文字中稱「視窗」，不要稱「scene」。
- 只在有幫助時開新視窗（例如撰寫郵件），並在情境選單或「檔案」選單提供「在新視窗中打開」。
