Popover 是在使用者點按控制項後，浮在內容上方的暫時視圖，箭頭指向觸發它的元素。

**使用者提供**：`arrow`（`top`、`bottom`、`leading`、`trailing`、`none`）、`width`、`title`、子元素。

- 只放少量資訊或幾個相關任務。
- 箭頭直接指向觸發元素，盡量不蓋住它或重要內容。
- 只有在能增加清楚度時才放關閉／取消／完成按鈕；否則點外部或選取項目即關閉。可多選時保持開啟直到使用者關閉。
- 自動關閉的非模態 Popover 要保存工作；只有明確按取消才捨棄。
- 一次只顯示一個，不要層層疊；除了 Alert，不要有東西蓋在 Popover 上。
- 大小只要容得下內容；尺寸變化要以動畫呈現。
- **iOS：compact 版面避免使用**，只在寬版面用；compact 改用全螢幕 Sheet。macOS 可讓人把 Popover 拖出成面板。
- 不要用 Popover 顯示警告——用 Alert。說明文字中不要出現「popover」這個詞。
