側邊欄位於畫面前緣，用來在 App 的區域或頂層集合（資料夾、播放清單）間導覽；在 iOS、iPadOS、macOS 可浮在 Liquid Glass 層上。

**使用者提供**：`sections`（`{title, items: [{value, label, icon, badge, children}]}`）、`value`／`defaultValue`、`onChange`、`floating`（玻璃浮動樣式，預設 true）、`width`、`header`。

## 規則（HIG Sidebars）
- 讓視覺豐富的內容延伸到側邊欄下方，強化分層。
- **最多兩層階層**；更深的資料改用分割檢視，在側邊欄與詳細內容之間放一欄內容列表。兩層時，每組用簡短的描述性標題。
- 大量內容用展開控制（本元件的展開三角）節省垂直空間。
- 項目使用 SF Symbols（網頁用本系統 `Icon`）；圖示預設用 App 強調色，macOS 中跟隨使用者選擇的系統強調色。固定顏色只在有明確目的時少量使用。
- 讓人能用平台慣用方式隱藏側邊欄，但預設不要隱藏。
- 可行時讓人自訂側邊欄內容。
- macOS：列高、文字與符號大小跟隨系統「側邊欄圖示大小」設定；視窗變窄時可自動隱藏；不要把重要資訊或動作放在側邊欄底部。
- 先考慮 Tab bar；需要大量區域時再用側邊欄。
