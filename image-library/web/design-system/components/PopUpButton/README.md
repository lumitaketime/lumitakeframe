彈出式按鈕顯示一組互斥選項中的「目前選擇」，按下後開啟選單更換。

**使用者提供**：`options`（`{value, label, disabled}`）、`value`／`defaultValue`、`onChange`、`label`（前導標籤，macOS 以冒號結尾）、`width`。

- 用於扁平、互斥的選項或狀態，空間有限、不需要同時看到所有選項時。
- 設定有用的預設值——大多數人會選的那一項。
- 讓人不打開選單也能預測選項：給前導標籤，或讓按鈕文字描述效果。
- 偶爾需要的項目可提供「自訂…」選項。
- 要列動作、多選或子選單時改用 PullDownButton。
- iPadOS：在 Popover 或模態視圖中，列表項目只有少量明確選項時，可用彈出式按鈕取代展開指示器。
- macOS 為有框按鈕＋右側強調色雙箭頭；iOS 為膠囊、文字用強調色。
