進度指示器讓人知道 App 沒有停住：能確定時長就用確定型（長條或圓環），不確定時用轉動的指示器。

**使用者提供**：`kind`（`bar`、`circular`、`spinner`）、`value`（0–1；不給即為不確定型）、`label`（無障礙名稱，描述正在做什麼）、`size`。

- 盡可能用確定型；知道時長後從不確定型切換成確定型。
- 進度準確、步調平均——不要 5 秒跑到 90%、最後 10% 花 5 分鐘。
- 保持移動；停滯的指示器看起來像當機。卡住時說明原因與可以怎麼做。
- 不要從圓形切換成長條。
- 說明文字精確簡短，避免「載入中」「驗證中」這類空泛字眼。
- 可以安全中止時提供「取消」；中止會失去進度時提供「暫停」，或以 Alert 確認。
- macOS：背景工作或空間有限時用 spinner，且不加標籤；不確定型長條只在 macOS。
