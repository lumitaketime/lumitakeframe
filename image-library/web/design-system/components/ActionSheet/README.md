動作表（iOS 確認對話框）：針對使用者剛發起的動作，提供相關的選擇。

**使用者提供**：`title`、`message`、`actions`（`{label, role, onPress}`）、`cancelLabel`、`onCancel`。

- 用來回應刻意發起的動作（例如取消郵件草稿時選「捨棄」或「儲存」）；描述問題或狀態改變時改用 Alert。
- 少用；標題一行；只在需要時加訊息。
- **破壞性按鈕放在最上方**並用破壞性樣式（本元件自動置頂）。
- 會刪除資料時提供取消，放在最下方獨立一組（SwiftUI confirmationDialog 預設就有）。
- 不要讓動作表捲動——捲動容易誤觸。
- iOS／iPadOS 中，跟在動作之後的選擇用動作表，不用選單；選單用來揭露選項。visionOS 不支援。
